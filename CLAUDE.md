# Working agreement

- Be concise. Don't restate the plan before executing it; report results, not narration.
- Route mechanical work (renames, reformatting, summarizing, scraping/extracting data) to a Haiku sub-agent via the Agent tool rather than doing it inline on the main model.
- Never suggest `/compact` as a cost-saving move. Compaction is a context-window tool, not a token-savings one — it re-summarizes and re-caches, which costs tokens rather than saving them.
